ReadPlate 3.0 — Fiji update site

This is a standards-compatible ImageJ update site for the ReadPlate macro by José María Delfino.

Install

  1. In Fiji, choose Help › Update… › Manage update sites.
  2. Enable ReadPlate. Until the canonical URL update is merged, use Add Unlisted Site with https://ghanerka.github.io/ReadPlate/.
  3. Apply changes and restart Fiji.
