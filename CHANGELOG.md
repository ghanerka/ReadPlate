# Changelog

## 3.0 — 2020-08-15

- Added support for 6 (3×2), 12 (4×3), 24 (6×4), 48 (8×6), and 96 (12×8) well plates.
- Added a new user interface for image analysis.
- Added user-defined controls for optimizing blank correction.
- Facilitated multiple readings of the same plate.
- Appended the full parameter record to the Results table and Log window.

## 2.1 — 2018-02-16

- Improved the blank-correction algorithm.

## 2.0 — 2016-04-15

- Added blank correction.

## 1.0 — 2015-12-16

- Initial release.

This changelog transcribes the history in the supplied macro header and documentation; it does not modify the original artifacts.
